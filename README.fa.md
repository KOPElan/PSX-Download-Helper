# راهنمای فارسی پروژه PSX Download Helper

**زبان‌ها:** [فارسی](README.fa.md) | [English](README.md)

PSX Download Helper ابزاری ویندوزی برای مدیریت و هدایت بخشی از درخواست‌های دانلود مرتبط با PSX از طریق پراکسی محلی است. مخزن دو نسخه مستقل را نگهداری می‌کند تا نسخه قدیمی با توسعه نسخه جدید تداخل نداشته باشد.

## نسخه‌های پروژه

| نسخه | فناوری | وضعیت |
|---|---|---|
| نسخه اصلی (Legacy) | .NET Framework 4.0 و Windows Forms | نسخه قدیمی؛ ساختار و شاخه اصلی آن حفظ می‌شود |
| نسخه مدرن (Modern) | .NET 10 و Windows Forms | مسیر توسعه مستقل در پوشه `Modern/` و شاخه `feature/modern-dotnet10` |

برای اطلاعات فنی، نصب و اجرای نسخه مدرن، [راهنمای فارسی نسخه مدرن](Modern/README.fa.md) را ببینید.

## قابلیت‌های نسخه مدرن

- پراکسی محلی با پردازش ناهمگام درخواست‌ها
- پشتیبانی از درخواست‌های HTTP و تونل‌سازی HTTPS با روش CONNECT
- ثبت درخواست‌ها و تنظیم IP و پورت شنود
- نگاشت نشانی دقیق HTTP به فایل محلی، همراه با پشتیبانی از درخواست‌های Range
- تعریف و مدیریت قوانین بازنویسی میزبان و مسیر CDN
- مدیریت نشانی‌های آفلاین و انتقال اطلاعات از فایل قدیمی `DataHistory.xml`
- واردکردن بخشی از تنظیمات نسخه قدیمی
- ابزار کمکی Wi-Fi برای بررسی و استفاده از قابلیت قدیمی Windows Hosted Network، در صورت پشتیبانی درایور

## دریافت و اجرا

بسته قابل انتشار نسخه مدرن به‌صورت مستقل برای Windows x64 ساخته می‌شود و به نصب جداگانه .NET Desktop Runtime نیاز ندارد. فایل ZIP و مقدار SHA-256 آن در بخش Actions مخزن، در خروجی اجرای موفق گردش‌کار انتشار قرار می‌گیرد:

[مشاهده اجرای ساخت بسته ویندوزی](https://github.com/meicamghe/PSX-Download-Helper/actions/workflows/modern-release.yml)

توجه: وجود بسته در Actions به معنی انتشار یک GitHub Release نسخه‌دار نیست. انتشار نسخه‌دار با ثبت tag مطابق الگوی `modern-v*` انجام می‌شود.

## ساخت نسخه مدرن از کد منبع

پیش‌نیازها:
- Windows 10 یا Windows 11 نسخه ۶۴ بیتی
- .NET 10 SDK
- Git

دستورها در PowerShell:

```powershell
git clone https://github.com/meicamghe/PSX-Download-Helper.git
cd PSX-Download-Helper
git checkout feature/modern-dotnet10
dotnet build .\Modern\PSXDownloadHelper.Modern.sln -c Release
dotnet run --project .\Modern\PSXDownloadHelper.Modern\PSXDownloadHelper.Modern.csproj
```

## نکات امنیتی مهم

- پراکسی به‌صورت پیش‌فرض فقط روی `127.0.0.1` گوش می‌دهد؛ این تنظیم برای آزمایش محلی امن‌تر است.
- برای استفاده از دستگاه دیگری در شبکه، فقط در شبکه خصوصی و مورد اعتماد، آدرس شنود را آگاهانه تغییر دهید و قانون Firewall محدود و مشخصی بسازید.
- پراکسی HTTPS را با CONNECT به‌صورت تونل رمزنگاری‌شده عبور می‌دهد؛ محتوای TLS رمزگشایی یا بازرسی نمی‌شود.
- برای کارکرد برنامه، گواهی ریشه سفارشی نصب نکنید و اعتبارسنجی TLS را غیرفعال نکنید.
- اگر در قوانین آفلاین Cookie ذخیره می‌کنید، آن فایل را محرمانه نگه دارید؛ Cookie ممکن است دسترسی نشست کاربر را فراهم کند.
- بسته‌های فعلی امضای دیجیتال ندارند. هش SHA-256 برای بررسی یکپارچگی فایل است و هویت ناشر را اثبات نمی‌کند.
- قابلیت Hosted Network در ویندوز قدیمی و منسوخ شده است و ممکن است در سخت‌افزار یا درایورهای جدید کار نکند.

## آزمون و آمادگی انتشار

CI ساخت پروژه، آزمون‌های خودکار و تولید بسته را بررسی می‌کند؛ اما جای آزمایش روی رایانه واقعی، نسخه‌های مختلف Windows، کارت شبکه و دستگاه مقصد را نمی‌گیرد. پیش از استفاده عملی، راه‌اندازی اولیه، پراکسی HTTP/HTTPS، نگاشت فایل، قوانین CDN و آفلاین، قطع و وصل ارتباط و Firewall را آزمایش کنید.
